# Image_Steganography
Developed an Image Steganography application in C that securely hides and retrieves secret messages within BMP image files using Least Significant Bit (LSB) encoding techniques. The project enables confidential data transmission by embedding text information into image pixels without causing noticeable visual changes.

Key Features:
- Hide secret messages inside BMP images
- Extract hidden messages from encoded images
- LSB (Least Significant Bit) based encoding
- Support for text file message embedding
- Preservation of original image quality
- Validation of image and secret file formats
- Error detection and handling
- Command-line interface for encoding and decoding

Technologies Used:
- C Programming
- File Handling
- Bitwise Operations
- Structures
- Linux Development Environment

Learning Outcomes:
- Understanding of steganography concepts
- Binary file manipulation techniques
- Image data processing
- Bitwise operations and data encoding
- Secure information hiding methods
- Software design and debugging practices

This project demonstrates the practical implementation of information security concepts by embedding confidential data within digital images while maintaining the visual integrity of the carrier image.
